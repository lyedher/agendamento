# **App Name**: Agendamento

## Core Features:

- User Registration: Allow new users to create an account by providing their personal data, including rank, ID, nickname, full name, work team, tax id, phone number, email, and password. Note: the storage layer must be developed by the user.
- User Login: Allow registered users to log in with their email and password.
- Login Redirection: Redirect logged-in users to the dashboard. A basic tool will reason about whether authentication has succeeded before allowing redirection to the protected dashboard.
- Forgot Password: Allow users to reset their password in case they forgot it.
- Create Account Link: Provide a link to the registration page for users who don't have an account.
- Input validation: The login and registration forms should validate data
- Main screen UI: The application shell UI is the primary interface that handles authentication flow.

## Style Guidelines:

- Primary color: Soft blue (#79A3B1) to create a sense of calm and security.
- Background color: Light gray (#F0F4F5) for a clean and modern look.
- Accent color: Light green (#ACC18A) for interactive elements like links and buttons.
- Body font: 'Inter', a sans-serif font for clear, readable text.
- Headline font: 'Space Grotesk', sans-serif, used to establish hierarchy
- Use simple, outlined icons for navigation and actions.
- Use a clean and intuitive layout to ensure that all elements on screen are clearly distinct.
- Use subtle transitions for page loading and interactive elements. For example, use opacity to achieve these, rather than position/size changes.
